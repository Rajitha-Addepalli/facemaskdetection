# 😷 Real-Time Face Mask Detection using CNN

This project is a Deep Learning Computer Vision application that detects whether a person is wearing a face mask or not in real-time using a webcam.

## 🚀 Features
- CNN-based image classification model
- Real-time detection using OpenCV
- Binary classification: Mask / No Mask
- Deployment-ready project structure

## 🛠 Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- CNN Deep Learning
